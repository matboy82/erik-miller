## Security, verification, and rollout

Google account credentials are not placed in the public website. Prefer a link or the owner-approved Google embed after accessible browser review. Minimize booking form fields and do not copy attendee PII into public assets/logs. If a server-side calendar/JobTread integration is selected after verification, it needs its own scoped authorization, token storage, event deduplication, retention contract, and Proposed ADR if it creates a new durable cross-service boundary.

Use browser checks for the schedule link/embed, accessible handoff, mode/copy, and qualified-only entry. External QA B1 covers account availability, DST, buffers, conflicts, Google confirmation/reminders, cancel/reschedule, and JobTread association using separately authorized synthetic accounts. Run `npm run check` and deployment dry-run; no account setup or deploy. If a later approved sync contract exists, its tests must cover duplicate events, ambiguous writes, privacy, and reconciliation. Rollback hides the booking entry point and preserves unresolved association records.
