## Purpose and boundary

This bounded capability-verification story can complete its local report, probe safeguards, and documentation work before authorized synthetic JobTread operations or account-specific booking verification. It does not claim those capabilities are verified and does not replace `$sdd-release`.

## Development/test exit

- Complete the durable report structure, official-documentation versus observed-evidence distinctions, sanitized evidence rules, and local probe safeguards.
- Test malformed/impossible/valid dates and leap-day boundaries; prove invalid plans stop before credentials or network access. Verify report handling for duplicate, partial, transient and recovery outcomes using deterministic simulations, clearly labeled as simulations.
- Document the owner-confirmed native booking gap and selected Google Appointment Schedule direction, while leaving account-specific entitlement and JobTread association unverified until evidence exists.
- Complete required local checks and resolve current review findings; live operation absence may be deferred only if this release spec is approved and does not block a dependent implementation contract.
