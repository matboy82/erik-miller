# Search and assistant-readable output

Current implementation and activation steps: [SEO/domain checklist](seo-domain-launch-checklist.md).

Dev serves production-domain canonicals, OG/Twitter tags, JSON-LD, sitemap and llms output for inspection while robots and meta/header noindex remain active. This separates technical preparation from permission to index incomplete content.

Use `SITE_BUILD=live`, `PUBLIC_INDEXING_ENABLED=false` during content/design feedback. Only enable indexing at domain cutover after client imagery, verified business facts/location and actual domain tests pass. The build rejects unresolved launch facts and used stock media; no SDD approval is manufactured.

`site.json` is the shared entity source. Unknown locations and profiles are omitted; Organization is emitted until a real public business location is verified. Visible FAQs and schema share records. No invented reviews, ratings or numerical proof are emitted.

Citations remain an external observed outcome. llms.txt is navigational guidance, not a guarantee. See the checklist's primary sources, exact pending owner inputs and fixed observation set.
